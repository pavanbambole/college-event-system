About CampusConnect

Smart College Event Management and Student Engagement System

Project Motivation

Transforming Campus Event Operations

In traditional college ecosystems, event notifications are distributed across fragmented noticeboards, WhatsApp groups, and unstructured Google Forms. This results in registration bottlenecks, missing ticket records, lack of real-time seat tracking, and manual attendance overheads.

CampusConnect is engineered to unify the entire student event lifecycle into an elegant, reactive, and reliable web application. Students can discover inter-departmental technical fests, workshops, hackathons, and sports meets, register with one click, receive instant digital passes with unique ticket IDs, and review past experiences.

JSON-Powered REST Engine

Built strictly according to TAE-I academic requirements using lightweight, resilient JSON file-based database serialization and Express.js REST API architecture.

Technology Architecture

High performance, zero external database daemon dependencies, fully modular.

Frontend

HTML5, Modern CSS3, Bootstrap 5.3, Bootstrap Icons, Vanilla ES6+ JavaScript.

Backend API

Node.js runtime & Express.js REST Framework with modular routers and controllers.

JSON Database

Atomic async file read/write operations with data normalization in data/*.json.

Security & Auth

JSON Web Tokens (JWT), Bcrypt password hashing, and role-based access control.

System Modules & Capabilities

Student Module

Student registration with validation, authenticated session management, event browsing with multi-parameter filtering, 1-click registration, digital ticket generation, event cancellation, and post-event feedback submission.

Administrator Module

Complete event lifecycle management (CRUD), real-time seat capacity tracking, student directory management, registration approvals/status changes, feedback moderation, and analytical dashboard charts.
